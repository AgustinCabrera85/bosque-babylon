# Gamepad SVG Icons

Set de iconos para prompts/HUD de juego.

## Estructura
- `xbox/mono/`: Xbox monocromático.
- `xbox/color/`: Xbox con colores convencionales en A/B/X/Y.
- `playstation/mono/`: PlayStation monocromático.
- `playstation/color/`: PlayStation con colores clásicos en ×/○/□/△.
- Cada plataforma incluye un sprite sheet SVG adicional.

## Tamaño
Todos los iconos individuales usan `viewBox="0 0 128 128"` y fondo exterior transparente.

## Incluidos
Xbox:
A, B, X, Y, LB, RB, LT, RT, LS, RS, D-pad, D-pad Up/Down/Left/Right, View, Menu, Home.

PlayStation:
Cross, Circle, Square, Triangle, L1, R1, L2, R2, L3, R3, D-pad, D-pad Up/Down/Left/Right, Create, Options, Touchpad, Home.

## Nota
Los botones Home usan un glifo genérico de casa en vez de logos de marca, para mantener el set neutral y reutilizable.

## Edición rápida
Los SVG son texto editable. Para cambiar el blanco, reemplazá `#FFFFFF`.
Para cambiar el fondo oscuro, reemplazá `#101318`.
